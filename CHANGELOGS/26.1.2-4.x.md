Changelog BBL Rooms

# 4.0.3
- Renamed "flags" to "restriction_options"
- Renamed "placement" to "placement_options"
- Added "item_required" option to placement options, this basically locks a structure behind an item that is consumed when the structure is consumed 

# 4.0.2
- Added palette system, allows template to have optional palettes which can be used to change teh structure appearance 
- Move improvements to the placer item 

# 4.0.1
- Greatly improved added new screens and better readability  

# 4.0.0
- DO NOT UPDATE TO THIS VERSION THIS IS STILL WIIPPPP
- This is a complete overhaul of the mod, every aspect of the mod has changed 
- Removed all blocks
- Removed KeyItem class
- Added Placer Item, shift right click to open a menu showing all valid structures. Click on a structure to select it for placement 
- Re done networking

# 3.1.0
- Name changed from Roomopolis to BBL Rooms

- Removed Core as dependency

# 3.0.0
- Updated to minecraft 26.1 snapshots
- Reworked Key Item basically a lot easier to create custom keys for mods
- Most key fields are optional now
- Added API for the KeyItemBuilder
- Added .rotation, this allow structures to be rotated in any direction respecting the rotation of the direction of the player when placing the key, this is optional and defaults to none
- Deprecated all blocks for removal in official 26.1 update
