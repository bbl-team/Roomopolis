Changelog BBL Rooms

# 3.1.0
- Name changed from Roomopolis to BBL Rooms
- Re enabled block rendering preview 
- Removed Core as dependency
- Added new auto updating

# 3.0.0
- Updated to minecraft 26.1 snapshots
- Reworked Key Item basically a lot easier to create custom keys for mods
- Most key fields are optional now
- Added API for the KeyItemBuilder
- Added .rotation, this allow structures to be rotated in any direction respecting the rotation of the direction of the player when placing the key, this is optional and defaults to none
- Deprecated all blocks for removal in official 26.1 update
